## 本轮：数据分析与行业分析

- `analysis_data.py` / `analytics.py`：完整范围统计、等长前期、缺失/零基期、分币种口径、累计快照、来源分类/关键词/站点及趋势。默认最近 7 天，支持 1/30 天和自定义范围；统计由代码计算。来源按批查询，不截断为生产环节的 40 条；报告读取按主题/范围查询，避免加载全部历史。
- `industry.py`：每批 20 项证据，公开和内部输入分开调用模型，验证引用、范围和待核实信息；保存覆盖、未处理、错误与调用数。为下游预留模型额度。无资料/额度不足保留明确状态，模型不生成数值指标。
- `business_files.py` / `business_validation.py` / `business_store.py`：UTF-8 CSV、标准 XLSX 流式读取；20 MB/10 万行/100 列限制，公式不执行，无缓存公式报错。四种模板、字段映射、日期格式/币种/增量或快照、无效行预览、预览令牌、文件与映射幂等、显式业务键去重、追加/替换/停用及不可变批次。插件 SQLite 新增 datasets/uploads/batches/rows 表及索引。
- 模型范围默认汇总，可选仅本地或经预览的脱敏字段；业务键及直接身份列不得发送，自由文本默认排除。明细每数据集最多 100 行，预览前 20 行；完整数据参与统计。公开权限单独选汇总指标，默认仅内部。数据集、权限和分析配置均有版本。

## 使用及边界

- 重启 Server 加载 Python 接口；开发 Desktop 刷新/HMR，发布包需重建。旧计划在运营蓝图明确勾选数据分析与行业分析后应用，不自动打开。
- 文件以本地数据库保存；模型调用使用当前配置的提供方，按数据集选项传送允许的内容。不新增 ERP、付费行业源、平台适配器或自动指标抓取。
- 行业结论依据采集样本和已导入数据；不能当作全行业统计。图片没有进行视觉行业分析。模型明细抽样上限与完整统计分开记录。
- 取消在下一次安全检查生效，已发出的模型请求不能撤回；权限变化后结果被丢弃。外部动作提交前重新核对，但不能撤销已被平台接受的提交。
- 分析导出默认内部；公开导出必须仍满足当前主题、时间范围和数据权限。历史报告仍保留用于本机内部审计。
