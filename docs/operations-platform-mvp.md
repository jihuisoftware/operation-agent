# 每日目标驱动的自动运营平台

更新：2026-10-31。本文取代原先“逐篇审核后执行”的 MVP 方案。实现与使用说明见[运营插件](../plugins/operations/README.md)。

## 运行方式

个人运营者、一个小红书账号。用户保存并启用运营规则后，平台按规则自动完成：

**每日任务 → 跨平台搜集 → 来源与知识整理 → 选题和图文 → 发布与互动 → 结果核对 → 日报与次日建议。**

Gateway 负责调度和业务状态，macOS Desktop 负责独立于聊天焦点的内嵌网页。最小化或隐藏画面不销毁执行页面，不打开系统浏览器。Mac 休眠或退出 Desktop 时不能执行网页任务。

## 当前实现

| 模块 | 实现与边界 |

| 场景模板与运营蓝图 | 定时任务双页签；八类业务主题及子类、六项执行场景及八项基础蓝图，可调整定位、模块、排期与规则；三步配置、草稿与启用分离；每 Profile 一套计划，重复应用更新模块，SDK 贡献入口与业务插件解耦 |
| 目标与规则 | 主题、品牌档案、受众、目标、风格、优先级、期限、账号、授权动作、时区、时间、每日额度；版本化保存 |
| 信息来源 | 指定网页、RSS/Atom、关键词，复用搜索与提取；检索覆盖小红书、知乎、B站、公众号、抖音可访问内容，不承诺全量 |
| 证据与知识 | 保留链接、可得作者/发布时间、采集时间、正文、内容指纹、失败原因；按日 URL 去重与正文去重；独立整理模块分类、保存摘要、事实陈述、观点和待核实信息，选题及内容引用已整理资料 |

| 素材和内容 | 上传授权图片，撤回授权，生成/编辑版本、自动质量检查；第一张图片作为封面，支持包含图片、正文、版本和来源的 ZIP 导出 |
| 图文发布 | 账号核对、任务素材上传、编辑器回读、提交；只有明确发布成功且获得笔记链接才记已发布，审核中为 submitted |
| 评论互动 | 读取带稳定标识的可见对象，结合原文生成评论/回复，发送前核对文本，结果证据不足记 unknown |
| 私信 | 仅回应已识别的收到消息，只能使用已确认知识原文；交易承诺、争议和敏感资料进入待处理 |
| 回关 | 独立开关，核对确实关注本账号、尚未回关且资料匹配条件；没有条件只保存候选 |
| 登录预检 | 五个常用平台的登录观察与确认时间；保留已确认登录直至明确失效，在线状态与验证要求单独提示；Profile 隔离、内嵌页面处理，真实 DOM 兼容性待联调 |
| 接管与恢复 | 全局暂停、能力暂停、人工接管、取消未执行动作、人工核对；未知结果不重试，确认未成功后才允许显式重试 |
| 日报 | 数据库记录生成，含来源、执行状态、待处理、可用指标、调用量、用量回执、未知费用、耗时与异常；应用内提示、Markdown 导出、离线补报 |

## 默认时间和限额

完整流程和业务主题默认选择采集、内容生产、发布、评论、收到私信回复及日报，预选对应动作授权；回关单独开启。旧计划在配置页通过“启用默认运营模块与授权”采用新配置，不修改原时间和较低额度，检查后应用才生效。

“立即执行”按独立批次运行选定模块，不受原排期和当天已完成记录限制。同批次重试不重做；暂停、额度、资料条件和未知结果核对仍有效。每批次保存日报快照，详情区分完成、跳过和失败。自动调度继续遵守原时间窗口。

时区 `Asia/Shanghai`，用户可配置：09:00 搜集、09:40 内容生产、10:00 发布，评论／收到私信／条件回关分别为 11:00 / 15:00 / 19:00，21:00 日报。每类可设多个执行时间。

每日来源 30 条、图文 1 篇、主动评论 5 条、评论回复 20 条、收到私信回复 10 条、回关 5 人。限额计入已占用但结果不明的动作，避免重启后释放额度导致重复提交；这是产品默认值，不是平台许可。失败不强行补量。

## 数据与技术约束

- 业务在独立 `operations` 插件中；不新增核心模型工具集、公共 API 或第二个常驻调度器。
- 私有接口挂在宿主已认证的 `/api/plugins/operations/`，继承 Profile 隔离。聊天查询、CLI 和桌面共用 SQLite 服务。
- 现有 Cron 执行 `no_agent` 脚本，每分钟检查每日时间表；同一账号租约和事务认领保证串行，步骤之间续租。
- 动作包含稳定 ID、账号、规则版本；同一个对象重复调度不会再次发送。执行命令有效期 120 秒，超时不推断成功。
- Desktop 通过插件 SDK 固定请求归属；切换 Profile 会卸载旧网页并重新绑定，旧回执不会写入新 Profile。规则编辑与人工接管使旧授权失效。
- 修改规则撤销待执行动作；执行中的动作每个步骤检查当前规则。已提交的动作不能承诺撤回。
- 登录、验证、账号或页面结构异常暂停相应能力，需处理并重新保存规则恢复。其他独立能力继续。
- 每个模块只补最近一次到期任务，更早时段直接忽略，不写入历史任务或错过执行记录；最近一次已有执行或人工取消记录时不回退补旧任务。跨天只补最近一份应生成的日报，其他业务动作计入实际执行当天的额度。报表是注明时间的不可变快照，后续核对保留在动作台账。
- 新插件工具仅在新会话进入工具集合，不改已有会话提示词缓存。

## 验收与后续联调

代码验证覆盖蓝图选择与预填、草稿不变更活跃计划、重复与并发应用、独立内容生产、旧规则和执行记录迁移、Profile 表单隔离，以及真实插件发现、宿主鉴权及 Profile API、真实 Cron 子进程、模拟来源/模型/网页、完整一天流水线、重复调度、跨天额度、去重、不可访问来源、规则暂停、账号不匹配、超时不重发、私信知识约束、回关条件和日报一致性。前端检查包括不确定提交、关注状态误判、重复文本回执和请求归属。

**尚未完成真实账号验收。** 当前网站 DOM、登录态、图片处理、消息入口以及真实 macOS 最小化行为，需要明确授权后的账号联调。识别失败会暂停并留下原因，不能把模拟测试通过等同于线上可用性验证。

自动视频制作/发布、AI 生成封面、自动提取全部平台指标、多账号并发、公众号/抖音自动发布仍不在首版。登录后资料采集适配器需要随真实页面继续扩充；当前公开网页/RSS 已接入，不能声称所有平台登录内容都可读取。
