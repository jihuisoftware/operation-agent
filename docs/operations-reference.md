# 产品与运行参考

[← 返回 App 介绍与快速上手](../README.md)

本文保留功能细节、运行规则、开发调试和打包说明。第一次使用，请先阅读 README。

基于 Hermes Agent 的运营助手，通过对话协助完成素材整理、选题、内容草稿、排期提醒和复盘。运营主题、品牌、受众与目标由用户定义，首批面向公众号、小红书和抖音，按实际需要选择渠道。

**主要入口为 macOS Desktop，界面仅支持简体中文。** 已加入每日目标驱动的运营插件：来源采集、规则授权、素材与内容版本、后台网页执行、互动台账和日报。模拟整日流程已验证，真实账号与网站兼容性仍待联调。详细任务与验收见 [MVP 方案](../docs/operations-platform-mvp.md)。

## 产品范围

模型提供方入口已按运营场景精简：保留深度求索、阿里云百炼、月之暗面、智谱、稀宇科技、小米、腾讯云、阶跃星辰，以及 OpenAI、Anthropic（Claude）、谷歌 Gemini、xAI（Grok）、OpenRouter、Fireworks AI、Ollama 云端、LM Studio 和自定义接口。国内／国际区域分别展示。Nous Portal 不再出现在提供方列表，并关闭首次使用的自动免费身份开通；云部署、编码工具专用及重复登录入口从默认列表隐藏。

范围与中文名称统一维护于 `hermes_cli/data/operations-profile.json` 的 `modelProviders`，由设置页、添加提供方和模型选择器共享。此裁剪不删除历史凭证、不改变已保存的提供方 ID，也不限制用户自行安装的其他提供方插件。

产品范围由 [operations-profile.json](../hermes_cli/data/operations-profile.json) 统一定义，后端与 Desktop 共用。旧配置不会重新启用本版已关闭的能力；范围覆盖不改写用户原始配置文件。

`gateway/`、`tui_gateway/` 与 `hermes_cli/web_server*` 继续服务 Desktop。业务能力优先通过技能和独立插件扩展；保留的 delegation、Kanban、MCP 底层代码用于共享运行时兼容，不表示产品已开放这些功能。

### 开发专用任务调试

使用源码 Server 和 `npm run dev --workspace apps/desktop`。在当前开发 Profile 的 `config.yaml` 中添加（合并已有 `development` 配置）：

```yaml
development:
  operations_debug: true
```

侧栏的「任务调试（开发）」可独立执行采集、资料整理、数据分析、行业分析、选题、内容生产、发布、主动评论、评论回复、私信、回关或日报。每次点击忽略原排期，只执行所选任务；依赖的来源、草稿和素材需提前准备。外部动作对应模块须已启用，暂停、账号、素材、回复知识和每日动作额度仍生效。详细执行使用计划授权，快速实测使用本次操作授权。开发调试的模型调用不受主题每日、Profile 总额或单轮次数限制，调用及 Token 用量照常记录，新调试调用不占用正常运营的模型额度。网页操作使用内嵌登录账号。

「快速实测（真实执行）」的模型调用不限次数，采集最多尝试一个查询和一条来源。点击即授权本批次直接执行真实图文发布、主动评论、评论回复、收到私信处理和条件回关，每种动作最多 1 次；单项按钮只授权所选动作，整链路按钮授权该批次的五种动作。授权不写入日常计划，真实动作仍占用每日动作额度。缺少账号、授权图片、有效草稿、回复知识或回关条件时，按实际检查说明原因。

本次授权绑定主题、关联账号、规则版本、执行批次和存活租约；请求重试不会重复执行，调试结束或条件变化后，尚未派发的动作取消。已经提交且结果不明的动作只做核对，不自动重发。旧客户端未携带真实执行标记时会提示刷新，不会悄悄把原预检查请求变成真实发布。

「开始整链路测试（真实执行）」按上述顺序串行运行，沿用当前规则，不自动开启模块或增加外部动作权限、额度；模型调用次数不限。采集、整理、选题、生产的依赖步骤未完成时停止对应后续步骤；发布绑定本轮生产的内容版本，不拿旧草稿替代。独立互动步骤继续检查，最后生成本批调试日报（即使日报模块关闭），不覆盖常规定时日报。未启用、未授权、无候选或结果待核对都会注明原因，不能当作全链路通过。执行中暂停、规则变化或跨天会阻止后续业务步骤。

草稿保存成功即表示内容生成完成；是否可发布单独检查图片与自动审核结果。发布条件不足时直接说明缺失项，不把已保存草稿笼统标成“内容未完成”。调试页同时显示当前网页控制状态，历史跳过记录不代表当前仍在接管。

调试页每个模块行的右侧展示近期批次状态、当前步骤说明和耗时，每两秒刷新；点击状态可打开对应批次详情。提交中与后台已开始执行分别显示，读取失败标注状态待刷新。整链路的待执行、运行中、完成、待检查、失败与跳过按各步骤分别投影，选择历史记录不会改写这些实时状态。

模型输入会精简历史快照，完整资料仍保存在本地；日志记录本轮输入字符数和实际覆盖范围。已确认发生在提交前的网页就绪超时可发起新请求重试，结果不明的提交仍只核对、不重发。

调试页实时展示步骤、产物、外部动作回执、异常堆栈和耗时，支持展开、复制完整记录、仅复制错误日志、复制单步或某块错误；连接和请求错误也能复制。记录保存在当前 Profile 的运营 SQLite 中，重新打开页面可查看；一次请求重试不会重复执行，再次点击生成新批次。Server 中断后显示中断，不自动重发结果不明的动作。调试会执行真实业务流程，开发时请使用独立 Profile 与测试数据。整链路模拟回归位于 `tests/devtools/test_operations_pipeline.py`，使用真实业务服务与数据库、模拟搜索/模型/桌面队列回执；通过它不代表真实网站发布按钮及互动页面已完成验收。

发布构建不包含调试页面或侧栏入口；后端开发工具放在 `devtools/`，从发布快照排除。接口只在源码检出中挂载，且默认关闭、按 Profile 检查上述配置。不新增常驻调度器。

### 小红书网页控制

[小红书技能](../skills/social-media/xiaohongshu/SKILL.md) 在 Desktop 中使用右侧内嵌网页进行搜索、读取和表单填写，上传文件由用户在面板选择。对于用户明确选择的独立自动化，另提供 `browser_exec` 脚本：

- 打开小红书与创作中心，识别需要登录或人工验证的页面。
- 按关键词搜索，读取笔记正文和当前可见评论，保留来源链接。
- 将指定本地图片交给网页上传框，并填写标题与正文。
- 回读编辑器核对内容，遇到已有不同草稿时停止覆盖。

Desktop 可直接在右侧页面登录，无需额外配置浏览器；独立自动化脚本需要配置可用浏览器。可在新会话中要求：“在右侧实时画面打开小红书，搜索我指定的主题，整理笔记链接和可见内容。”具体调用方式、上传前提与状态说明见技能文档。

当前脚本不执行发布，也不确认草稿已保存到草稿箱。上传请求已发出不等于平台处理完成；读取范围仅限页面可见内容。离线行为测试已通过，真实账号登录、上传处理与当前网站页面兼容性仍需联调。新增技能在同步后通过新会话使用，保持已有会话的提示词缓存稳定。

### 浏览实时画面

点击桌面窗口右上角的地球图标「显示浏览实时画面」，在右侧直接打开网页。这里是可交互的内嵌页面，用户和智能体操作同一页面，支持输入网址、登录、跳转与滚动。

- 在面板地址栏输入网址，或在对话中要求“在右侧实时画面打开小红书”。智能体通过 `desktop_preview` 打开和读取页面，通过 `drive_preview` 操作，不另开系统浏览器。
- 再次点击地球图标可隐藏面板，再打开保留当前网页；页面按会话归属，沿用 Desktop 现有的标签页与配置隔离。
- 独立浏览器或云浏览器中的页面不会自动搬入此面板；它们的登录状态也不共享。需要时在面板内重新登录。文件上传由用户在面板选择文件。
- 更新代码后重启 Server 与 Desktop；新会话采用新的浏览指引。旧会话可明确要求“使用 desktop_preview 在右侧打开网页，使用 drive_preview 操作，不使用独立浏览器”。

## 电脑睡眠与任务恢复

运营网页任务执行时会接入「设置 → 高级 → 保持电脑唤醒」：选择「运行期间」可防止空闲自动睡眠，屏幕仍可熄灭；选择「关闭」时保留该选择。合盖、手动睡眠等仍可能中断任务。

电脑实际进入睡眠时，当前网页命令停止派发，保存已完成结果。唤醒后自动只读检查账号；检查通过显示“账号已确认，等待手动继续”，不会自动发布、评论或发送私信。检查失败可点击运营画面的「重试账号检查」，人工接管期间不抢占网页。

在「任务 → 运营台账与临时任务」中点击「检查账号并继续未完成步骤」恢复同日有效批次。跨天、规则或账号变化时应按当前条件重新发起。已提交或结果未知的动作先核对，不能通过重跑重新发送。

后续任务受此前中断影响时，会明确显示“本次尚未执行”，并提供原始发生时间和「查看原始任务」入口。历史错误、原执行尝试和人工核对结论都会保留；旧记录缺少电源证据时不会自动归因为睡眠。

此功能需同时更新并重启 Server 和 Desktop。先等待后台空闲，再停止旧后台并启动；重启本身不解除已有生产阻塞。

## 每日自动运营

首次打开进入**首页 → 快速开始**：选择业务类型、具体主题和工作方式，即可开始运营。主题支持手动添加，默认自动运营；研究分析和准备内容也可单独使用。目标、受众、风格和排期按场景预填，常用与详细设置可稍后展开。未连接模型时提供连接入口，也可先保存计划。

**多业务、多主题**：侧栏顶部选择业务空间与运营主题。工厂、商家等是业务类型，同一类型可以建立多个独立业务；每个业务可以有多个主题及独立计划。改名保留历史，新方向通过“新增主题”建立独立分区。新增或复制配置保持未启用，不复制执行记录；切换页面不会停止其他已启用主题。未保存设置切换前会提示，选择会按 Profile 保存。

- 资料、分析、选题、内容、执行历史和日报默认属于当前主题；首页“业务运行汇总”可看当前业务或全部业务。记录链接携带业务和主题归属。
- 同一业务共享授权素材与回复知识；来源通过资料页明确引用其他主题，并保留原始出处。不同业务默认不共享资料。业务数据的模型权限、公开权限及发布前检查保持生效。
- 每个业务默认独立登录空间；在业务管理中可以明确关联同一账号。共用账号共享登录、网页执行队列、额度和消息认领，同一条消息不会由多个主题重复回复；待处理事项可转交给共用账号的主题，转交不会立即发送。
- 运营画面可以切换查看账号；窗口隐藏、业务切换不销毁后台网页。暂停主题、暂停业务、暂停全部运营相互区分，人工接管只暂停相应账号的网页动作。登录分区按账号 ID 隔离。
- 仍使用每个 Profile 的一个 Cron，主题间按阶段轮转；手动请求持久化并按主题去重。创建新业务或主题不会增加 Profile 采集/模型总额，主题限额和账号共享额度同时约束执行。
- 开发阶段不维护旧数据兼容：不迁移旧库、不建立历史待归属区、不转换旧规则或恢复旧页面链接。使用新版需清理旧开发运营数据，重新配置业务。新版产生的执行记录、日报和归档功能正常保留。

存储采用 Profile 内的 `plugin-data/operations/workspaces.db` 目录及共享台账和 `topics/<稳定主题ID>.db` 主题账本；文件均由后端解析，客户端只能传业务/主题 ID。CLI 可用 `hermes ops status --business-id <ID> --topic-id <ID>` 查看指定主题；多个主题时必须明确指定业务和主题；可用 `hermes ops workspaces` 查看 ID。

| 主入口 | 功能 |
| --- | --- |
| 首页 | 当前目标、实时进展、成果、待处理与日报 |
| 任务 | 统一运营计划、正在运行、待执行、任务与历史 |
| 资料 | 来源、整理分类、授权图片、业务数据导入 |
| 分析 | 数据分析、行业分析与历史报告 |
| 内容 | 选题、草稿、待发布、发布记录与成果文件 |
| 互动 | 评论回复、主动评论、收到私信、回关 |

账号、AI 助手、设置、扩展工具位于侧栏底部；扩展工具保留终端和插件管理，调试入口仅开发版显示。已有用户恢复原页面，任务完成不会抢占当前页面；旧链接跳转到对应分类并保留查询参数。

**开始运营**会保存当前规则并安排一次快速首轮：最多尝试读取 20 条来源、最多 3 个检索查询，受当天剩余额度约束；不会改写每日 10,000 条或用户更低的额度。步骤串行执行，已就绪的发布与互动仍通过原有授权、账号、内容和额度检查。首轮请求、进度和日志持久化，重试和重开不会重复启动同一首轮；用户另行点击“立即执行”才发起新的手动批次。阶段结果持续展示，支持取消、复制完整日志或错误日志。

账号、素材和回复知识可以稍后补充；缺少条件显示在对应功能，不阻止采集和分析，也不阻止整份计划保存。补齐后默认等待下次排期，不直接触发外部动作。新计划不会补跑启用前的旧时段；旧计划继续只补最后一次超期任务。**保存，稍后开始**只保存新计划；已有计划的“保存设置”保留启停状态。

所有“调整运营设置”进入 **任务 → 运营计划** 同一个编辑面板。常用设置含时间、数量和动作开关；常用设置还支持按次数或 Token 配置每日模型预算，新计划默认 200 次/天；全部主题共享预算单独保存。详细设置含来源、知识、受众、风格和回关条件。已有自定义值不重新套用默认值，替换时展示具体差异。业务数据的模型读取与公开权限仍在数据集设置中独立维护。

日期使用日历选择，执行时间使用时钟控件；多时段逐条添加或删除，无需输入逗号分隔格式。时间按运营计划时区执行，截止日期留空表示长期运营。普通定时任务也可直接选择执行时间、星期或每月日期，高级自定义表达式仍可使用。品牌、来源网址、真实回复知识等业务资料按需填写。

**资料整理与归类**位于采集与选题之间，默认 09:10。进入 **运营管理 → 资料整理** 查看图文卡片、分类、摘要、事实陈述、观点、待核实信息和出处，可搜索、筛选、展开和复制。按当前主题增量整理（包括历史未整理资料），每批四条；模型漏返时保存有效结果，仅对缺失来源单条补试一次，仍受模型额度限制；额度不足显示待整理数量，下次继续，不重复消耗已完成资料。选题与内容主要使用已整理资料并保存引用关系；没有可用整理结果会明确跳过，原文仅用于核对。历史资料用于生产仍需在采集页选为长期素材；参考图不自动获得发布授权。已有计划升级时，为已启用的采集/选题/生产加入整理模块，继承采集时间，保留外部动作权限、额度和已执行记录。

**采集执行规则**：按运营主题与每个关键词分别检索通用网页及五个平台站点范围，每次最多十二个查询，跨批次将各查询结果数量从 20 扩大到 50、100；这是搜索范围扩展，不是平台原生翻页，也不保证全量采集。显式网址、RSS 和发现的候选链接一并入队；未读取候选、查询进度和每批统计保存在当前 Profile 数据库。默认每天一万次正文读取尝试，沿用用户更低的额度；失败与重试也计数，每个链接当天最多三次，成功链接当天跳过。异常、登录或验证码短页面不会作为有效正文进入整理，失败后清除该链接提取缓存供下次重试。按保守 URL 规范化与空白归一后的正文去重，保留签名参数、出处、可取得的作者/发布时间和参考图片；正文超过一万字符时保存头尾片段并显示截断提示。

采集页新增最近批次统计及复制入口，区分读取成功、新资料、正文重复、已采集跳过、读取失败和未尝试。日报保留各批统计；部分失败会标记待完善，已取得的有效资料仍可进入后续整理。采集仍使用现有搜索/提取服务，不会调用扫码登录的内嵌网页采集。

**信息采集**和**选题策划**是独立模块，各自有开关、排期、调试和执行记录。前者检索并保存来源，不生成选题；后者读取已整理的分类资料，不重新采集。进入 **运营管理 → 选题管理** 可查看候选与依据、选择候选，或直接输入具体题目。指定选题仅保存至当前 Profile、当天及当前运营主题，下一次内容生产使用它；不立即生成、发布，也不改写已有草稿。没有手动选择时使用最新批次的首个推荐；启用了选题模块但缺少结果时，内容生产明确跳过。

**运营管理 → 信息采集 → 来源素材库** 用图文卡片展示采集资料，支持搜索、分页和查看全文、摘要、作者、原始链接、采集时间及内容引用记录。新采集保留图片链接，最多保存三张不超过 2 MB 的 PNG/JPEG/WebP 参考图片到当前 Profile 本地，其他图片保留链接；没有图片或下载失败时明确显示文字资料，不伪造配图。正文及图片索引存入运营数据库，图片预览通过已认证私有接口读取，不在界面直接加载远程图片。

当天同主题资料自动供选题使用；点击“加入长期素材”后，历史来源可跨天供当前主题的选题和内容生产使用，并优先进入选题模型的四十条来源预算。点击“取消长期复用”仅取消历史固定选择，不删除来源或既有内容版本；当天同主题来源仍可自动使用。选择按 Profile 和运营主题隔离，保留资料原始日期。参考图片没有自动获得发布权限，发布仍只使用素材库中明确授权的图片；未获取原图的来源展示正文。

首页以指标卡和分区展示当前目标、实时执行、今日成果、待处理和最新日报；点击进入对应资料、分析、内容或互动页面。账号登录独立放在侧栏底部，所有运营设置统一进入任务的计划页。

总览每五秒读取轻量数据库汇总，隐藏时暂停刷新，切换 Profile 隔离数据；不是从最近 100 条列表推算总数。今日统计使用计划时区，具体时间按本机时区显示。只有核对成功的发布和互动计入成果，待核对提交单独列出；内容统计为版本数，候选选题取当日最近一次结果。查看总览不会启动任务或改变授权。

新计划默认选择采集、整理、两项分析、选题、内容生产、发布、评论、收到私信处理与日报；发布、评论、私信开关直接展示，回关默认关闭。账号采用内嵌网页当前扫码账号，也可在详细设置中绑定。修改已有计划不会自动增加权限或额度。设置页的运营入口只跳转到统一编辑面板，不再维护另一份表单。

**任务**是侧栏主要入口，包含“运营计划”“正在运行”“待执行”“任务与历史”。选择任务后点击“立即执行”，或从任务菜单手动触发；运行中或提交中的任务不可重复触发，执行记录在任务详情查看。运营任务的“立即执行”忽略各模块原排期，已完成模块也会重新执行。每次点击建立新批次，同一次请求重试不重复执行；仍遵守计划暂停、账号、素材、回复知识、每日额度和未知结果核对。运行详情逐项显示完成、跳过及失败原因，每批次保存一份新的日报快照。自动调度按模块排期执行；错过多个时段时，每个模块只补最近一次到期任务，更早时段直接忽略，不写入历史任务、步骤或“错过执行”记录。最近一次已执行或被人工取消时，不回退补更早任务。跨天恢复只补最近一份应生成的日报；业务动作使用实际执行当天的额度，已有历史记录保留。

点击右上角「运营画面」打开右侧独立分栏，原页面向左收缩，画面用边框、标题栏和状态栏明确区分；拖动分栏分隔线可调整宽度。收起后主页面恢复空间，网页与后台任务继续保留。平台登录统一在侧栏底部「账号」操作。该执行页面独立于当前聊天，按连接与 Profile 隔离登录状态；登录或人工接管只暂停对应 Profile 的网页动作，完成后点击「结束接管」；不会解除主动设置的全局暂停。Mac、Server 和 Desktop 需保持运行。

运营画面启动时自动加载小红书首页；隐藏再打开保留当前网页，连接刷新不重置页面。同一连接与 Profile 继续使用原有持久化登录数据，重新打开不会主动清除登录。页面加载中、网络失败或网页进程退出会显示明确状态及恢复入口。平台明确退出、登录过期或设备登录超限仍需重新扫码，保存登录数据不能绕过平台的会话限制。

后台执行使用独立 Worker 时钟维持心跳和网页等待，避免窗口隐藏后被误判离线。导航以实际加载事件为准，上传与提交后的检查等待页面状态，不依赖固定延时；页面异常会保留具体原因。动作与执行命令在同一数据库事务中入队，提交后结果不明只进行核对，不自动重发。

发布前的重复检查只比较已核对发布的内容，修改中的草稿不会与自身旧版本误判重复。自动检查记录实际范围：文本及素材元数据检查不代表已完成图片视觉审核。未核对的提交标为待处理，不计入已成功发布或互动；日报按持久化台账汇总。

发布记录分别保存执行、平台审核和内容核对状态。提交成功页没有笔记链接时，执行器比较发布前后的账号笔记列表，只对唯一新增候选进行作者、标题、全文和图片核对；找不到、出现多个候选或平台状态不明确时保留待核对，不重复提交。平台图片按顺序与授权原图做 SHA-256 比对，转码或下载失败显示核对不完整。审核中不计为核对成功，后续复用现有调度进行只读复查；缺少审核证据的结果不视为已核对。

在内容的发布记录或互动记录中展开「网页执行步骤与证据」，可查看步骤状态、耗时、结果及异常现场截图，并复制完整过程、仅错误或单条记录。步骤和截图保存在当前 Profile 的 SQLite 数据库，重启后仍可查；调试批次日志同步包含关联网页事件。截图读取失败会记录原因。新增发布核对流程已通过临时数据与模拟页面测试，仍需另行验证真实页面兼容性。

在「内容 → 发布记录」或「互动」可查看异常分类、下一次核对时间、最终稿图文预览和人工核对历史，也可点击「立即核对（不重发）」或导出本动作诊断 ZIP。人工结论追加保存，保留原链接、自动核对事实和修改前回执；迟到的自动结果不能覆盖人工结论。

发布提交与只读核对使用独立命令和超时：提交回执入库后再排队核对，不等待图片比对完成才保存发布结果。审核中按退避间隔继续检查，最长跟踪七天；网络或无法确认的结果最多自动检查八次，内容不一致、审核拒绝转人工处理。审核状态变化会在应用内提示。原图与平台图可显示尺寸、解码像素是否相同及缩略图相似度，均为人工参考，不能代替文件哈希一致的自动结论。

「日志与截图存储管理」可查看数据库占用、选择 7～365 天保留期限、手动清理或开启每日自动清理。默认保留 30 天、自动清理关闭；未解决异常、最终稿、人工结论及仍被引用的截图保留。清理释放的数据库页供后续复用，不承诺文件立即缩小。诊断 ZIP 包含动作记录、快照及日志，排除密钥、Cookie 和图片文件，URL 查询参数会去除；截图仍可在应用中查看。

每个主题有独立运营计划，同一 Profile 共用一个调度任务。模块可独立排期，默认每天 09:00 采集、09:10 资料整理、09:12 数据分析、09:16 行业分析、09:20 选题、09:40 内容生产、10:00 发布，评论、私信、回关各在 11:00 / 15:00 / 19:00 检查，21:00 日报。重复应用更新当前计划，保留原有较低额度；移除模块停止后续执行，历史记录保留。内容生产可无账号运行并保存缺图片草稿；发布只消费当天已保存的候选版本。支持素材授权撤回、内容版本编辑、ZIP 内容包导出、指标导入、异常核对和 Markdown 日报。未知结果不自动重发，缺少素材或来源时允许不发布。

**账号**是侧栏底部的独立页面，与任务及运营设置分开，覆盖小红书、知乎、B 站、微信公众号后台和抖音。显示已登录、需要登录／验证、无法确认及上次检查时间；小红书账号与规则不一致时单独提示。点击“检查／登录”先接管网页，再在内嵌页面处理，完成后点击“结束接管”。已确认登录后持续保留，时间经过、窗口重启、离线或暂时无法识别不会清除“已登录”；只有明确退出或登录失效才改为“需要登录”。验证要求、账号不匹配和执行窗口在线情况单独提示，任务执行前仍核对实际账号。检测不保存 Cookie、密码或登录令牌，真实页面兼容性仍待联调。

选择任务后打开“任务详情与实时进度”，可点击查看当前计划、历史批次、执行时的规则快照、各步骤状态及完整结果；展开时每 3 秒刷新，支持复制。运营任务会逐步记录来源读取、模型生成、等待桌面执行和已保存产物；普通任务未上报分步进度时明确提示，不猜测完成比例。计划快照、步骤、事件和输出按 Profile 保存到 `cron/executions.db`，重启后仍可查看，保留范围随现有执行台账（每 Profile 最近 1000 个终态批次），页面列出任务最近 50 批次。未上报步骤的任务仅展示实际运行输出。

「任务 → 正在运行」显示当前连接及 Profile 的 Server、心跳、运行中的定时任务，以及 Desktop 已接收的 Agent 会话进度、工具参数、结果和错误；可展开复制。「任务 → 待执行」列出运营计划今天剩余及明天的各模块步骤、当前手动批次尚未开始的步骤，以及普通定时任务的下一次执行。每项可取消本次步骤，取消记录写入数据库，后续日期和新的手动批次不受影响。普通任务作为一个脚本／Agent 执行单元取消，不预先编造尚未生成的工具调用。已经开始的步骤会拒绝待执行取消，不把已经提交的外部动作标成已撤销。

配置和恢复步骤见[运营插件使用说明](../plugins/operations/README.md)。现有小红书技能仍用于对话中的浏览和填写；自动发布/互动由运营插件规则和执行台账管理。2026-11-01 已在明确授权下完成单篇真实图文发布及作者、标题、全文、封面核对；发布控件、图片上传等待和标题预览同步问题已修复。标题遗漏在同一笔记上更正，未重复发布；本轮未执行评论、私信或回关。消息入口、全天自动运行和真实最小化运行仍需另行验收，单篇测试不代表所有平台流程已通过。

侧栏会在 Agent 会话、定时任务、开发调试或打开登录页面期间显示动态图标与执行数量，任务与 AI 助手等入口分别显示执行信号。无需打开详情页：会话随事件更新，定时任务及调试每 3 秒核对；完成后图标消失。等待排期、等待人工输入或扫码不显示执行动画。连接/Profile 切换会清空旧状态；读取失败显示静态提示，连续失败三次后暂停轮询，重新聚焦窗口可重试。

信息采集默认每天最多 10,000 条，任务中的统一设置支持调整到此上限；已有计划保留已保存的额度。上限不等于每次执行的采集数量，检索、读取和去重仍按实际结果记录。

## 数据分析与行业分析

侧栏「分析」包含「数据分析」和「行业分析」。完整流程现在为采集 → 整理 → 数据分析 → 行业分析 → 选题 → 内容生产。两个分析模块可在任务的详细设置中启用，支持定时执行、忽略排期的「立即分析」、取消和开发模式下的单模块／全链路调试。调整已有计划不会自动开启新模块，也不会提高额度；当前开发版不迁移旧数据库。

数据分析默认使用最近 7 天，与前一个等长周期比较，可选择今日、30 天或自定义日期。来源趋势、分类、关键词和站点覆盖属于采集样本，不代表行业规模。金额和数量由本地代码计算；缺失数据不补零，没有可比基期不计算增长率，不同数据集、币种及口径分别展示。累计快照按商品／渠道／平台取最新有效值。

「业务数据」支持 UTF-8 CSV 与 XLSX，提供销售订单、商品表现、获客转化、内容表现模板。每个文件最多 20 MB、10 万行；选择工作表、匹配字段、指定日期格式和口径、检查预览后保存。Excel 不执行公式，公式没有缓存值时需先转成数值。重复文件和映射不会重复导入；只有明确选择业务键时才跨批次去重。可追加、替换或停用数据集，历史批次与分析版本保留。

每个数据集单独设置「模型可读取的数据」和「允许文章使用的汇总指标」：默认只发送汇总、仅内部使用；可以选择仅本地使用，或预览并选择脱敏明细字段。直接身份字段与业务键不得发送，自由文本默认排除。明细每个数据集最多发送 100 行，前 20 行可预览；完整数据仍参与本地统计。公开指标另行勾选，原始明细不进入自动发布内容。权限改变后，旧分析不能继续作为自动生产和公开导出的依据。

行业分析分为内容运营与市场经营视角，展示趋势、需求、竞争、产品价格、机会及风险；结论保留证据、适用范围、反向证据和待核实事项。行业、地区及关注对象支持选择和手动添加，未设置地区时不生成地域结论。模型按批次解释资料，保留实际覆盖和未处理数量，不把额度不足当作全量完成。公开与内部业务证据分开调用模型。分析不足时，选题降级到已整理资料并记录原因；权限已失效的旧选题或稿件需重新生成检查。

报告、统计口径、数据批次、权限版本和执行日志保存在当前 Profile 的插件数据库。可查看历史、打开引用的原始图文、导出内部或可公开 Markdown、导出图表 CSV，并复制完整执行过程或仅错误。运营总览展示最新报告，日报列出分析产出、导入异常与降级情况。第一版不连接 ERP 或付费行业数据源；表格保存在本地，按用户保存的选项向当前模型提供方发送允许的数据。

## 主题与运营目标

在 Desktop 对话中说明主题、受众、目标、渠道及可用素材即可开始。例如：

> 我想围绕“城市步行”做小红书内容，面向周末出游人群。先根据我提供的照片提出三个选题，再为选中的题目写图文草稿。

> 我还没有确定运营方向。请先了解我的素材和目标，提供几个候选主题，由我选择。

示例主题不作为系统默认值。助手沿用当前任务已确认的信息，缺少真实素材、数据或授权时明确说明；内容草稿、发布建议与实际执行结果分别报告。

可通过对话讨论主题，也可在「任务 → 运营计划」保存主题、项目／品牌档案、目标和运营规则；设置中的自动运营入口跳转到同一编辑面板。主题变化以新消息追加，不重写历史上下文；不同 Profile 的素材、事实、账号授权和指标不自动混用。

模型预算的计量规则、Token 回执未知时的处理和共享设置见[运营插件说明](../plugins/operations/README.md#可配置模型预算)。

## 本地开发

需要 macOS、Git 和 Xcode Command Line Tools。运行时与开发工具由仓库的 PM 环境准备，Node/npm 版本约束见根目录 [package.json](../package.json)。

开发时将 Server（Gateway）和 Desktop 分别放在两个终端运行。以下命令均在仓库根目录执行，两边必须使用相同的 `HERMES_HOME`。

终端一：准备环境，每次都先停止已有 Server，再在前台启动；`-v` 将详细运行日志输出到当前终端：

```bash
export HERMES_HOME="$HOME/hermes-operations-dev"
export HERMES_RUNTIME_DIR="$HERMES_HOME/tools"
source ./activate
./.hermes/bin/hermes gateway stop
./.hermes/bin/hermes gateway run -v
```

等 Server 启动完成后，在终端二启动 Desktop：

```bash
export HERMES_HOME="$HOME/hermes-operations-dev"
export HERMES_RUNTIME_DIR="$HERMES_HOME/tools"
source ./activate
npm ci # 首次运行或依赖变更后执行
HERMES_DESKTOP_HERMES_ROOT="$PWD" npm run dev --workspace apps/desktop
```

`activate` 准备并激活开发环境；`npm ci` 安装整个仓库工作区的前端依赖。重新打开终端时，使用相同的数据目录并再次激活。启动后在 Desktop 中配置模型与凭证；图片、视频等服务按需配置。环境管理细节见仓库 PM 文档。

首次使用独立数据目录时，模型列表为空是因为尚未配置提供方；其他安装或 Profile 的模型与凭证不会自动继承。在模型选择弹窗点击「添加提供方」，完成登录或填写 API Key，再选择模型。也可以在已激活的开发环境运行 `./.hermes/bin/hermes model` 完成配置，随后重新打开 Desktop 的模型选择器。

「添加提供方」和设置页提供 Kimi、DeepSeek 的直接入口。Kimi 默认进入中国区密钥配置，国际区可在密钥表单中切换；请使用对应区域开放平台的 API Key。保存后选择模型并确认即可使用，模型列表由后端目录提供。凭证申请与接口说明见 [Kimi 中国区](https://platform.kimi.com/docs/api/overview)、[Kimi 国际区](https://platform.kimi.ai/docs/api/overview)和 [DeepSeek](https://api-docs.deepseek.com/zh-cn/)。

也可直接进入「设置 → 模型」，在「提供方」下拉框选择尚未配置的提供方，填写 API Key 并点击「连接」，再选择并应用模型。聊天中的模型选择器只展示已配置提供方的模型。

Desktop 通过 `hermes gateway ensure --json` 发现并连接已运行的 Server，HTTP API 和 WebSocket 均由该 Gateway 提供，无需另外启动 `hermes serve`，也无需手动指定后端端口。`5174` 是 Desktop 的 Vite 开发服务端口。当前 Desktop 在找不到 Gateway 时仍会自动启动后端，并非仅连接模式。

若之前已经由 Desktop 启动了后台 Gateway，先退出 Desktop，在相同开发环境执行以下命令，再执行终端一的前台启动命令：

```bash
hermes gateway stop
```

关闭 Desktop 不会停止 Server。结束调试时，先退出 Desktop，再在 Server 终端按 `Ctrl+C`；也可在相同开发环境执行 `hermes gateway stop`。

需要独立的 Desktop 数据与应用实例时，在已准备好的开发环境中使用：

```bash
scripts/dev-sandbox.sh -- npm run dev --workspace apps/desktop
```

默认退出时清理临时数据；加 `--persistent` 可保留用于后续调试。配置、凭证与历史按 Profile 隔离，行为设置写入 `config.yaml`，密钥写入 `.env`。启动排错与连接说明见 [Desktop 文档](../apps/desktop/README.md)。

### 节省 Token 模式

在 **设置 → 模型 → 节省 Token 模式** 中启用后，默认关闭图像和文件解析；两个开关可独立选择，也可全部关闭。保存到当前配置 Profile，其他 Profile 不受影响；关闭节省模式恢复原有解析行为。

- **解析图像**：控制新附图、视觉模型分析及工具返回的原生图片。关闭时在读取像素／调用视觉模型前返回说明。
- **解析文件**：控制附件 `@file:` 的内容展开，以及 PDF、Office 等文档的正文提取。PDF 作为图片处理需同时允许图像与文件解析。
- 仅影响后续新输入和解析调用，不删除附件、素材或历史，不重写对话缓存。已有上下文仍可能计费；需要清空旧上下文时新建会话。
- 本地上传、预览、业务表格导入继续可用；业务数据的模型读取与公开权限仍由数据集设置单独控制。普通文字、网页正文和代码读取仍可能产生 Token，此模式不是总量或费用硬上限。

配置对应 `config.yaml`：

```yaml
token_saving:
  enabled: true
  parse_images: false
  parse_files: false
```

```bash
# Desktop 类型、界面与 Electron 测试
npm run typecheck --workspace apps/desktop

# 小红书控制脚本与技能规范
```

## 发布命令

以下命令均在仓库根目录运行。普通桌面打包用于检查当前 UI 和应用外壳，不会准备一份全新的 Agent 运行时：

```bash
# 生成未封装的应用目录，不上传产物
npm run pack --workspace apps/desktop

# 生成 macOS DMG / ZIP，不上传产物
npm run dist:mac --workspace apps/desktop -- --publish never
```

需要包含 Python、Node、Agent 依赖与托管工具的完整本地安装包时，先提交待打包的代码，确保工作区干净，再运行：

```bash
scripts/build-bundle.sh
```

完整构建打包当前 `HEAD`，产物位于 `apps/desktop/release/`。脚本不推送代码、不发布 Release；本地包不经过 Apple 公证，不能代替正式发布验收。

正式分发还需完成目标架构验证、签名、公证、安装与更新验收，并配置当前运营分支自己的发布仓库和更新渠道。完整流程见 [构建指南](../apps/desktop/BUILDING.md)；请同时核对本分支的 CI 与发布配置。上游 Hermes 安装包不等同于本运营版产物。
