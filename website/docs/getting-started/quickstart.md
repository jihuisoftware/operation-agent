# 运营版快速开始

当前版本提供通用运营能力，主题由用户输入或选择；公众号、小红书和抖音是首批渠道。主要入口为 macOS Desktop，界面固定为简体中文。首次使用先按[安装说明](./installation.md)准备本分支环境。

## 1. 验证基础对话

在 Desktop 中配置模型提供商、模型与凭证，发起一条普通对话。确认响应正常后，再验证浏览器、文件、图片生成等实际需要的能力；这些能力受模型和服务配置影响。

本地 Gateway 由 Desktop 获取或启动。不要为桌面聊天额外启动浏览器 Dashboard、消息机器人或独立 `serve` 进程。

## 2. 输入或选择运营主题

直接在对话中输入本次主题；尚未确定时，可以请助手依据你的兴趣、业务或资源提供候选，再选择或修改。候选不是默认行业，自定义主题同样适用。已提供的主题不需要反复选择。

确定主题后补充品牌名称、目标人群、运营目标、渠道、语气偏好，以及有来源和使用范围的图片、视频或事实资料。缺失信息保持未知，不要求模型补造经历、授权或运营成绩。

可以从以下任务开始：

> 我还没确定运营主题。请根据我提供的业务资料给出三个候选方向，说明适合的受众与所需素材，等我选择后再制定内容计划。

也可以直接输入：

> 本次主题是城市步行，受众是周末出游的新手，目标是获得路线讨论与收藏，先运营小红书。请根据附件中的实地记录生成图文草稿，列出来源、资料缺口和待人工审核的问题。

上述主题仅用于演示，可以替换为任意用户定义的方向。当前通过对话输入或选择候选；独立主题选择页、模板保存和结构化运营档案仍待开发。主题变更作为新的用户消息追加，不重写历史或中途替换系统提示词。

## 3. 审核内容并人工发布

逐平台检查事实、素材授权、表达和格式。抖音脚本完成不等于成片完成；内容文件导出不等于已经发布。

当前素材台账、不可变内容版本、审批记录、发布回填与增长报表仍待开发。现阶段需要人工保存审核结果、外部链接及发布证据，不能把聊天记录当作已实现的业务审批系统。

## 4. 使用提醒和复盘辅助

定时任务可以承载提醒；指标文件可以交由 Agent 分析。核对数据来源、时间窗口和缺失值，并人工保存证据。自动去重导入、持久化发布状态及可追溯增长报表属于后续业务模块。

## 当前功能边界

- 保留记忆、技能、文件、浏览器、终端、待办和定时任务。
- 当前关闭多 Agent 协作工具、Kanban 工具与自动派单、MCP 服务、公共 API／Webhook。
- Bot Mode、内置消息平台适配器、Kanban／Radio 界面和浏览器 Dashboard 前端已移除。
- Profile 用于配置与历史隔离；旧配置不会重新开放已关闭能力。

后续实现顺序为：素材到内容包 → 发布与互动台账 → 指标复盘。完整计划见仓库 `docs/operations-platform-mvp.md`；当前范围见[平台支持](./platform-support.md)。
